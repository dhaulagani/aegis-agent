# Git Diff Blast-Radius Engine (`aegis diff`)

The Blast-Radius Engine inspects unified git diffs generated by AI coding agents and quantifies the structural risk of the patch on a scale from **0 (Safe)** to **100 (Catastrophic)**.

---

## 🧮 Scoring Formulation

The risk score is calculated using four composite factors:

1. **Critical Vulnerabilities (+50 pts each):**
   - Private key exposures (`-----BEGIN RSA PRIVATE KEY-----`).
   - Destructive filesystem commands in shell scripts (`rm -rf`, `shutil.rmtree('/')`).
   - Destructive SQL statements (`DROP DATABASE`, `TRUNCATE TABLE`).
   - SSL/TLS verification disabled (`verify=False`, `NODE_TLS_REJECT_UNAUTHORIZED='0'`).
   - Remote code execution vectors (`eval(request.body)`).

2. **High Severity Violations (+25 pts each):**
   - Permissive file permission changes (`chmod 777`).
   - Hardcoded cloud credentials (`AKIA...`, `ghp_...`).
   - Unsandboxed shell execution (`subprocess.run(shell=True)`).

3. **Sensitive File Touches (+10 pts per file):**
   - Touches to `.env`, `.github/workflows/`, `auth.py`, `crypto.py`, `settings.py`, `payment.py`, or master secrets.

4. **Code Churn Factor (0 to 20 pts):**
   - Added and deleted lines normalized over standard patch sizes.

---

## 💻 CLI Usage

```bash
# Analyze staged or unstaged git diff directly:
git diff | aegis diff -

# Analyze saved diff with strict threshold:
aegis diff pull_request.diff --strict

# Output machine-parseable JSON:
aegis diff patch.diff --json
```
