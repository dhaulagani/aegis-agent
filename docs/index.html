Native Model Context Protocol (MCP) Setup

Add AegisAgent natively to your Claude Desktop, Antigravity, or Cursor environment:

// claude_desktop_config.json or mcpSettings.json
{
  "mcpServers": {
    "aegis": {
      "command": "aegis",
      "args": ["mcp"]
    }
  }
}
